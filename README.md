# Luma Blocks

Мобильная браузерная головоломка без сборщика, внешних библиотек и сетевых ресурсов.
Поле и фигуры построены на DOM/CSS, а состояние хранится в `localStorage`.

## Запуск в VS Code

1. Откройте в VS Code папку `block-puzzle`.
2. Установите расширение **Live Server**, если оно ещё не установлено.
3. Откройте `index.html` и выберите **Open with Live Server**.
4. Игра откроется на `http://127.0.0.1:5500` (порт может отличаться).

Service Worker доступен только на `localhost`/`127.0.0.1` или HTTPS. Не открывайте
`index.html` двойным щелчком через `file://`: PWA и офлайн-кэширование так не работают.

## Установка на телефон

Для установки с телефона разверните содержимое этой папки на HTTPS-хостинге
(например, статическом хостинге) и откройте HTTPS-адрес в браузере:

- **Android:** Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
- **iPhone:** Safari → «Поделиться» → «На экран Домой».

Первый запуск должен быть онлайн, чтобы Service Worker загрузил и закэшировал
оболочку приложения. Откройте игру один раз и дождитесь завершения загрузки.
После этого её можно запускать без сети. Обновления файлов подхватываются
Service Worker при следующем сетевом запуске; при изменении оболочки обновите
суффикс `CACHE_NAME` в `service-worker.js`.

На iPhone не требуется отдельная кнопка установки в самой игре: установка
выполняется через меню Safari. Рекорд, звук и число начатых партий сохраняются
локально в браузере.
